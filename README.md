# Tiiny API notes (unofficial)

Field notes on the network API of the **Tiiny Pocket**: every endpoint I've found, what was actually
tested, recipes, quirks, and a tool to see what changed after a TiinyOS update.

> **These are my personal findings**, from my own Tiiny, and a work in progress. I'll keep updating them as I
> learn more about the device and as new features turn up. They are not official documentation and may be wrong
> or out of date for your TiinyOS version.

**Not affiliated with Tiiny.** Everything here comes from calling my own device with its own API key, the specs it
publishes, Tiiny's public docs and the TiinyOS desktop app. Behaviour can change with any update; each section
says which version it was checked against. Corrections welcome (issues/PRs).

## Checking your own device

```bash
export TIINY_URL=http://192.168.1.50 TIINY_KEY=your-api-key   # TiinyOS → Settings → API Key
python tools/api_snapshot.py            # first run saves a baseline in snapshots/ (not committed)
python tools/api_snapshot.py --check    # later: what changed?
```

Something not working? Test just that part, or everything:

```bash
python tools/api_test.py ocr             # one section: info chat embeddings ocr image audio music 3d
python tools/api_test.py                 # full run (loads ~10 models in turn; 20-40 minutes)
python tools/api_test.py --list          # every check and the model it uses
python tools/api_test.py --via usb       # label the run; then --via wifi, and compare:
python tools/api_compare.py snapshots/api-test-*/report.json
```

It loads the models it needs (and puts back what was loaded before), checks each answer against known inputs in
`tools/assets/`, and prints PASS/FAIL/SKIP per check; a report and the outputs land in `snapshots/`.
Don't use the Tiiny for anything else while it runs.

Python 3.10+, standard library only. The key is only sent to the address you give.

## Ground rules for this repo

- Only things anyone can check with their own device and API key. No root/firmware internals, nobody's
  addresses, keys or data, and security issues go to Tiiny privately first.
- Mark what was **tested** versus only seen in a spec or the docs.
